# Architecture

The compiler is a pure TypeScript boundary with a small command-line adapter.
Structured JSON or YAML is parsed, normalized, and compiled into Product IR.
Readiness is evaluated before executable artifacts are created. A `READY`
result emits Product IR, readiness, executable specification, Goal DAG,
diagnostics, and a compilation receipt. A `NOT_READY` result emits the partial
Product IR, readiness, diagnostics, and receipt only.

Canonical hashing sorts identity/reference collections and omits operational
timestamps. Semantic sequences such as the core loop and vertical-slice stages
retain their declared order. The source compiler is canonical; the tracked
plugin runtime and schema copies are generated by `scripts/build-plugin.mjs`.

The plugin wrapper changes to its own plugin directory before schema
validation, so it is independent of the caller's current working directory.
Output writes are anchored to the verified output-directory inode during a
synchronous phase; no-force commits use atomic hard links, regular-file
collisions require `--force`, and symlinks are refused even when force is
supplied. See [the security policy](../SECURITY.md) for platform boundaries.
