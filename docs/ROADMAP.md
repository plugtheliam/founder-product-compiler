# Roadmap

The roadmap is a public hypothesis list, not a promise of dates. Priorities
will change as reproducible examples, maintainer capacity, and user evidence
improve.

## Now

- Maintain the English-first, multilingual documentation contract.
- Make the skills-only Codex plugin easy to install from an immutable release
  commit.
- Expand deterministic fixtures for readiness, compilation, and the
  readiness-based product-judge decision helper.
- Publish reproducible showcase examples without private product data.

## Next

- Add a small benchmark harness for product-brief completeness, readiness
  findings, and cross-run determinism.
- Collect anonymized, opt-in feedback from real projects and publish the
  measurement method before making comparative claims.
- Improve contributor workflows for translations, schemas, and fixture-based
  regressions.
- Prepare the materials required for public Codex plugin directory review.

## Later

- Add Code, Journey, and Thesis product-judge evidence adapters while keeping
  local-first defaults.
- Explore richer visual reports for Product IR and Goal DAG review.
- Add additional language packs when a maintainer can keep them aligned with
  the canonical English contract.

## Evidence standard

Any future claim that the compiler improves product outcomes should identify
the baseline, sample, task definition, measurement, and limitations. Until
that evidence exists, the project describes its design goals and reproducible
behavior rather than promising to outperform another product.
